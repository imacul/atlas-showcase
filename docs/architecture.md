# How Atlas thinks about the product

Atlas is built around three user-facing ideas:

1. Understand the interface.
2. Recreate it as useful design material.
3. Check the result before presenting it.

The details behind those ideas are part of Atlas's private implementation. This page intentionally stays at the product level: Atlas is designed to work with the rendered experience people see in a browser and turn that experience into editable Figma work.
