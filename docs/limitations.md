# Public limitations

Atlas is currently focused on public, browser-renderable interfaces. Results can be incomplete or withheld when a site requires login, blocks automation, relies heavily on canvas/WebGL, contains unresolved iframes, fails to load assets, or renders beyond safe page-size limits.

Atlas does not reproduce backend behavior, application databases, authentication, or business logic inside Figma. Its current output is an editable visual reconstruction and, where available, a set of discovered page/state frames.

The public showcase deliberately contains no private URLs, credentials, customer data, raw conversion payloads, or implementation source.
